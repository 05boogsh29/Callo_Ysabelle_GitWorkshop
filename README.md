Project Title: Call of Duty: Mobile Tactical Dashboard

Brief Description:
The Call of Duty: Mobile Tactical Dashboard is a simple game information webpage designed to present important details about Call of Duty: Mobile using a tactical military-style interface.

The project uses HTML and CSS to create a static dashboard with a sidebar navigation system. Users can view different sections such as the Command Center, Game Intel, Operations Database, Player Reports, and About the Game. Each section contains specific information organized in a clean and interactive dashboard layout.

The project was developed through multiple versions using Git, where each version introduced new features and improvements while maintaining the original design structure.

Reflection:
Creating this project helped me understand how websites can be developed gradually through different versions using Git. Instead of creating the whole system at once, I learned how each update can improve the project by adding new features while keeping the previous work organized.

I also learned how HTML and CSS work together to create a structured and visually appealing interface. Designing the tactical dashboard allowed me to practice creating layouts, navigation systems, and content sections without using JavaScript.

Through this activity, I realized the importance of proper version control because every change in a project should be documented and managed properly. Git makes it easier to track progress, improve designs, and maintain the project as it grows.

Difference between git add and git commit:
In my own understanding, git add and git commit have different purposes.

git ad is used to prepare or stage the changes that I want to include in the next update. It tells Git which files or modifications should be recorded.

git commit is used after git add to save those staged changes permanently in the project's history. It creates a record of the changes together with a message describing what was updated.

In simple terms, git add selects the changes, while git commit saves those changes as a new version of the project.
