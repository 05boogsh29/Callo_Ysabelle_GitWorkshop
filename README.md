# Remote Repositories and Branching with GitHub

This activity demonstrates the use of Git and GitHub for managing project versions and collaboration.

## Description

The activity covers connecting a local Git repository to GitHub, pushing projects, synchronizing changes using fetch and pull, and creating a separate feature branch for development.

## Objectives

- Connect Git with a GitHub remote repository
- Push and update project files
- Use fetch and pull commands
- Create and manage branches
- Commit and push new features

## Tools Used

- Git
- GitHub
- Visual Studio Code
